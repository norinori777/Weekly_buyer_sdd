# Quickstart: 購入済み通知の確認手順

## 自動テスト

```powershell
cd weekly_buyer
flutter test test/widget_test.dart
flutter analyze
```

## 手動確認

1. アプリを起動し、購入リストに未購入の商品を用意する。
2. 商品を購入済みにする。
   - 黒色背景の通知が出ないこと。
   - 画面内に「購入済みにしました」と「元に戻す」が 1 組だけ表示されること。
3. 何も操作せず 3 秒待つ。バナーが消えること。
4. もう一度購入済みにし、3 秒以内に「元に戻す」を押す。商品が未購入に戻り、バナーが消えること。
5. 購入済みにした直後に「商品追加」タブへ移動し、購入リストへ戻る。バナーが再表示されないこと。
6. 続けて 2 件を購入済みにする。最新の商品のバナーが表示され、最後の操作から 3 秒で消えること。
