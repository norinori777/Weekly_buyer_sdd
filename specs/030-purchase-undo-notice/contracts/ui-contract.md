# UI Contract: 購入済み通知

外部 API はなく、画面上の振る舞いを契約として定義します。

## 購入済み操作 (購入リスト画面)

| 項目 | 契約 |
|------|------|
| 黒色背景の通知 (SnackBar) | 購入済み操作では表示しない (文言も「元に戻す」も出さない) |
| 画面内バナー (`UndoBanner`) | 購入済み操作の直後に 1 つだけ表示する。「{商品名} を購入済みにしました」と「元に戻す」を含む |
| 表示時間 | 表示開始から 3 秒で消える。別の購入済み操作で置き換わった場合は 3 秒を数え直す |
| 「元に戻す」 | 押すと商品が未購入に戻り、バナーが消える |
| 画面遷移 | 下部ナビゲーションなどで別画面へ移動した時点でバナーが消える。戻っても再表示しない |
| 読み取り専用 (前の週) | バナーを表示しない |

## 変更しない表示

- 「先にカテゴリを追加してください。」の SnackBar
- 「{商品名} を商品マスターに登録しました」の SnackBar
- 音声入力開始失敗の SnackBar

## 検証可能な観測点

- 購入済み操作後に `find.byType(SnackBar)` が 0 件。
- 購入済み操作後に `find.text('元に戻す')` が 1 件。
- 2 秒経過時点では 1 件、3 秒経過後は 0 件。
- 3 秒以内に「商品追加」タブへ移動し、戻ったときに 0 件。
