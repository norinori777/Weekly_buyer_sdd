# Feature Specification: 購入済み通知の重複解消と自動消去

**Feature Branch**: `030-purchase-undo-notice`  
**Created**: 2026-10-25  
**Status**: Draft  
**Input**: User description: "購入リストにて購入済みにした場合、購入済みした旨と元に戻すが画面下部に表示されますが、現状2つ同じ内容が表示されているため、黒色の背景の通知の方の購入済み通知を表示しないようにする。また、購入済みと元に戻すリンクの表示は、ずっと表示されているが、3秒したら消えるようにする。画面遷移した場合も消えるようにする。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 購入済み通知の重複を解消する (Priority: P1)

購入リストで商品を購入済みにすると、画面下部に「購入済みにした旨」と「元に戻す」操作が2か所に重複して表示されている。利用者には1か所だけ表示されるようにする。黒色背景の通知は、メッセージの文言だけでなく通知そのもの(「元に戻す」を含む)を購入済み操作では表示しないようにし、同じ内容が二重に見えないようにする。

**Why this priority**: 同じ内容が二重に出ることは混乱を招く最も目立つ不具合であり、単独で改善価値がある。

**Independent Test**: 購入リストで商品を1つ購入済みにし、画面下部に「購入済み」の旨と「元に戻す」が重複せず1組だけ表示されることを確認する。

**Acceptance Scenarios**:

1. **Given** 購入リストに未購入の商品がある, **When** 商品を購入済みにする, **Then** 画面下部に購入済みの旨と「元に戻す」が重複せず1組だけ表示される。
2. **Given** 商品を購入済みにした直後, **When** 画面下部を確認する, **Then** 黒色背景の通知は(文言も「元に戻す」も含め)表示されない。
3. **Given** 購入済み通知が表示されている, **When** 「元に戻す」を押す, **Then** 商品は未購入に戻る。

---

### User Story 2 - 通知を3秒で自動的に消す (Priority: P1)

購入済みの旨と「元に戻す」の表示は現在ずっと表示され続けている。表示から3秒経過したら自動的に消えるようにする。

**Why this priority**: 表示が残り続けると画面下部の操作を妨げ、不要な情報が居座るため。

**Independent Test**: 商品を購入済みにし、何も操作せず3秒待って通知が消えることを確認する。

**Acceptance Scenarios**:

1. **Given** 購入済み通知が表示されている, **When** 操作せず3秒経過する, **Then** 通知(購入済みの旨と「元に戻す」)が消える。
2. **Given** 購入済み通知が表示されて3秒以内, **When** 「元に戻す」を押す, **Then** 商品が未購入に戻り、通知が消える。
3. **Given** 通知が表示されている最中に別の商品を購入済みにする, **When** 新しい購入済み操作を行う, **Then** 新しい商品の通知が表示され、そこから3秒間表示される。

---

### User Story 3 - 画面遷移時に通知を消す (Priority: P2)

購入済み通知の表示中に別の画面へ遷移した場合、通知はその時点で消え、遷移先の画面や戻った画面に残らない。

**Why this priority**: 無関係な画面に古い通知が残ると誤操作や混乱の原因になるが、頻度は3秒消去より低い。

**Independent Test**: 商品を購入済みにして3秒以内に別画面(例: 他タブや商品追加画面)へ移動し、通知が表示されないことを確認する。

**Acceptance Scenarios**:

1. **Given** 購入済み通知が表示されている, **When** 別の画面へ遷移する, **Then** 通知が消える。
2. **Given** 通知を表示したまま別画面へ遷移した, **When** 元の購入リスト画面へ戻る, **Then** 以前の通知は再表示されない。

### Edge Cases

- 通知が出ている間に複数の商品を続けて購入済みにした場合、最新の1件分のみが表示され、最後の操作から3秒で消える。
- 3秒経過して通知が消えた後は、「元に戻す」ではその操作を取り消せない(商品の状態は購入済みのまま。購入済み商品自体の別の戻し手段は従来どおり)。
- 通知の消去と「元に戻す」操作がほぼ同時に起きても、商品の状態が不整合にならない。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 購入リストで商品を購入済みにしたとき、購入済みの旨と「元に戻す」は画面下部に重複せず1組だけ表示されなければならない。
- **FR-002**: 購入済み操作では、黒色背景の通知自体を表示してはならない(メッセージの文言だけを除くのではなく、通知全体を出さない)。
- **FR-003**: 購入済みの旨と「元に戻す」の表示は、表示開始から3秒経過した時点で自動的に消えなければならない。
- **FR-004**: 利用者は、表示中に「元に戻す」を押して商品を未購入に戻せなければならない。押した後は通知が消えなければならない。
- **FR-005**: 通知表示中に画面遷移が行われた場合、通知は直ちに消え、遷移先や戻り先で再表示されてはならない。
- **FR-006**: 通知表示中に別の商品を購入済みにした場合、通知は最新の商品の内容に置き換わり、3秒の表示時間は新たに数え直されなければならない。

### Key Entities

- **購入済み通知**: 商品を購入済みにした直後に表示される一時的な通知。対象商品名、購入済みの旨、「元に戻す」操作、表示時間(3秒)を持つ。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 商品を購入済みにした際、同じ内容の通知が画面上に同時に2つ以上表示される割合が0%である。
- **SC-002**: 購入済み通知は、操作がない場合に表示開始から3秒(±0.5秒)以内に消える。
- **SC-003**: 通知表示中に画面遷移した場合、100%の確率で遷移後の画面に通知が残らない。
- **SC-004**: 表示から3秒以内に「元に戻す」を押した場合、100%商品が未購入に戻る。

## Assumptions

- 対象は購入リスト画面での「購入済みにする」操作に伴う通知のみで、他の通知は変更しない。
- 「黒色背景の通知」とは、画面下部に出る一時的なメッセージ表示のことで、もう一方(画面内に常設される購入済み表示)を残す前提とする。残すのは「元に戻す」操作を含む画面内の1組の表示である。
- 3秒の起点は通知が表示された時点とする。
- 既存の購入済み商品の表示方法や購入状態の保存方法は変更しない。
