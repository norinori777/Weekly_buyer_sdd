# Feature Specification: 購入リストへの使用日表示

**Feature Branch**: `029-usage-date-display`  
**Created**: 2026-10-25  
**Status**: Draft  
**Input**: User description: 「購入リストに商品の使用日を表示するようにしてください。使用日は、商品追加画面で曜日から商品を追加しますが、その曜日が商品を使用する日となるため、そこから使用日を表示するようにしてください。表示形式は『使用日:MM/DD(曜日)』。また、購入日にもラベルを付与し、購入日に曜日も表示する。購入日と使用日を一緒に表示する場合は『購入日:MM/DD(曜日) 使用日:MM/DD(曜日)』。例: 使用日:10/26(月)、購入日:10/25(日) 使用日:10/26(月)。」

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 購入日と使用日を確認する (Priority: P1)

買い物中の利用者として、購入リストで商品の購入日と使用日を曜日付きで確認したい。購入した日と使う予定の日を一目で把握し、買い物や使用の予定を判断できる。

**Why this priority**: 購入リスト上で日付情報を直接確認できることが、この機能の中心的な価値である。

**Independent Test**: 購入日と使用曜日が設定された商品を購入リストに表示し、日付ラベル・日付・曜日の順序と値を確認する。

**Acceptance Scenarios**:

1. **Given** 購入日が2026年10月25日で使用曜日が月曜日の商品があり、対象週が2026年10月26日(月)から11月1日(日)である, **When** 対象週の購入リストを表示する, **Then** 商品に「購入日:10/25(日) 使用日:10/26(月)」と表示される。
2. **Given** 購入日と使用日がある商品が購入リストに表示される, **When** 日付情報を確認する, **Then** 購入日が使用日より前に表示され、両方にラベルと曜日が付く。
3. **Given** 購入日が2026年10月25日で使用曜日が設定されていない商品がある, **When** 購入リストを表示する, **Then** 購入日だけが「購入日:10/25(日)」と表示される。

### User Story 2 - 使用日を確認する (Priority: P2)

買い物中の利用者として、購入日がない商品でも、商品追加時に選んだ曜日から使用日を確認したい。

**Why this priority**: 購入日が未設定の場合にも使用予定を把握でき、曜日を基準に商品を追加する既存の利用方法を支援する。

**Independent Test**: 使用曜日が設定され、購入日がない商品を購入リストに表示し、使用日だけが指定形式で表示されることを確認する。

**Acceptance Scenarios**:

1. **Given** 使用曜日が月曜日で購入日がない商品があり、対象週が2026年10月26日(月)から11月1日(日)である, **When** 購入リストを表示する, **Then** 商品に「使用日:10/26(月)」と表示される。
2. **Given** 商品の使用曜日が対象週の日曜日である, **When** 購入リストを表示する, **Then** 使用日は対象週の終了日の日付と日本語の曜日略称で表示される。
3. **Given** 対象週の使用日が月の初日である, **When** 購入リストを表示する, **Then** 月と日はそれぞれ2桁で表示される。
4. **Given** 使用曜日が設定されていない商品がある, **When** 購入リストを表示する, **Then** 使用日ラベルや推測した使用日は表示されない。

### Edge Cases

- 購入日が未設定の場合は購入日ラベルを表示せず、使用日があれば使用日だけを表示する。
- 使用曜日が設定されていない商品には、推測した使用日を表示しない。
- 対象週は月曜日から日曜日までとし、月またぎの週でも選択された曜日に対応する対象週の日付を使用日として表示する。
- 日付の月・日が1桁の場合も、月と日をそれぞれ2桁にそろえて表示する。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 購入リストの対象週（月曜日から日曜日まで）に対し、使用曜日が設定された商品は、その曜日に対応する対象週内の日付を使用日として表示しなければならない。
- **FR-002**: 使用日は「使用日:MM/DD(曜日)」の形式で表示し、月と日は2桁、日本語の曜日略称は「月・火・水・木・金・土・日」の1文字で表さなければならない。
- **FR-003**: 購入日がある商品について、購入日を「購入日:MM/DD(曜日)」の形式で表示しなければならない。
- **FR-004**: 購入日と使用日の両方がある場合、購入日を先に、使用日を後に表示し、全体を「購入日:MM/DD(曜日) 使用日:MM/DD(曜日)」の形式にしなければならない。
- **FR-005**: 購入日がない場合、購入日ラベルを表示せず、使用日があれば使用日だけを表示しなければならない。
- **FR-006**: 使用曜日がない場合、使用日を生成または表示してはならない。
- **FR-007**: 表示する日付と曜日は、各日付の実際の暦上の曜日と一致しなければならない。

### Key Entities

- **購入リスト商品**: 購入リストに表示する商品。使用曜日と、設定されている場合は購入日を持ち、対象週内の使用日および日付表示に関係する。
- **使用曜日**: 商品追加時に選択された曜日。購入リスト上で対象週の使用日を決める情報。
- **購入日**: 商品を購入した日。購入リスト上で曜日付きの日付として表示する情報。
- **対象週**: 購入リストが示す週。月曜日に始まり日曜日に終わる7日間であり、使用曜日を具体的な日付に対応させる期間。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 使用曜日が設定された購入リスト商品は、検証対象の全曜日・全ての月またぎケースで、対象週の正しい日付と曜日を使用日として表示する。
- **SC-002**: 購入日と使用日がある商品の表示は、検証対象の全ケースで指定の順序・ラベル・「MM/DD(曜日)」形式を満たす。
- **SC-003**: 購入日のない商品では購入日ラベルが表示されず、使用日がある場合は使用日だけを確認できる。
- **SC-004**: 購入日と使用日の有無による4通りすべてで、購入リストに該当する日付情報だけが所定の形式で表示され、未設定の日付ラベルや日付が表示されない。

## Assumptions

- 表示対象の購入日は、商品に既に記録されている購入日を使用し、この機能では購入日の記録方法を変更しない。
- 使用日は商品追加時に選択された曜日を、購入リストが示す月曜日始まり・日曜日終わりの対象週の日付に対応させて求める。
- 月と日はゼロ埋めした2桁で表示し、年は表示しない。
- 曜日は日本語の1文字略称（「月・火・水・木・金・土・日」）を使用する。
- 購入日と使用日が両方ある場合は、購入日を先、使用日を後に表示する。
