# Quickstart: 商品追加画面の料理メニュー編集

## Goal
商品追加画面で、登録済みの料理メニューをペンアイコンから編集できることを確認する。

## Prerequisites
- Flutter SDK が利用可能であること。
- `weekly_buyer` プロジェクトが開けること。

## Validate

```powershell
cd weekly_buyer
flutter analyze
flutter test
```

## Manual flow
1. 商品追加画面を開く。
2. 既に登録済みの料理メニューの右側にあるペンアイコンを押す。
3. 編集用の入力シートが、対象メニューの内容を初期表示した状態で開くことを確認する。
4. 内容を変更して保存し、その 1 件だけが更新されることを確認する。
5. もう一度ペンアイコンを押し、キャンセルして閉じる。
6. キャンセル後に元の内容が残っていることを確認する。

## Expected results
- ペンアイコンから編集を開始できる。
- 編集シートには元の文字列が入っている。
- 保存後は対象 1 件だけが更新される。
- キャンセルでは元の内容が変わらない。
- read-only の前の週表示では編集導線が無効になる。
