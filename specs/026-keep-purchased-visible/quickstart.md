# Quickstart: 商品追加画面の購入済み商品表示

## Goal
商品追加画面で、購入済みの商品が一覧から消えず、商品名と数量の文字色が購入済みを示す色に変わることを確認する。

## Prerequisites
- Flutter SDK が利用可能であること。
- `weekly_buyer` プロジェクトが開けること。

## Validate

```powershell
cd weekly_buyer
flutter analyze
flutter test
```

## Manual flow
1. 商品追加画面を開く。
2. 商品を 1 件購入済みに切り替える。
3. その商品が一覧から消えずに残っていることを確認する。
4. 商品名と数量の文字色が購入済みを示す色に変わることを確認する。
5. 別の商品は未購入の見た目のまま残っていることを確認する。
6. 購入済みを元に戻して、通常の文字色に戻ることを確認する。

## Expected results
- 購入済み商品は非表示にならない。
- 購入済み商品の商品名と数量だけが色で区別される。
- 未購入商品は従来どおりの見た目のまま。
