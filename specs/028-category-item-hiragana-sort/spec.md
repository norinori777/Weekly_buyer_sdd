# Feature Specification: 購入リスト画面カテゴリ内商品のひらがな順ソート

**Feature Branch**: `028-category-item-hiragana-sort`  
**Created**: 2026-05-24  
**Status**: Draft  
**Input**: 購入リスト画面のカテゴリ内の商品の並び順は、ひらがなの昇順でソートするようにしてください。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - カテゴリ内の商品がひらがな昇順で並んでいることを確認する (Priority: P1)

買い物をする人として、購入リスト画面を開いたとき、各カテゴリ内の商品がひらがな読みの昇順（あいうえお順）で並んでいるので、目的の商品をすばやく見つけたい。

**Why this priority**: 商品の並び順は購入リスト画面の視認性に直結し、日々の買い物操作の効率に大きく影響するため最優先。

**Independent Test**: 複数の商品（読み順がバラバラ）が登録されたカテゴリを持つ購入リスト画面を開き、各カテゴリ内の商品がひらがな昇順で並んでいることを確認する。

**Acceptance Scenarios**:

1. **Given** 同一カテゴリ内に複数の商品が登録されている状態で、**When** ユーザーが購入リスト画面を開くと、**Then** そのカテゴリ内の商品がひらがな読みの昇順（あ→い→う…）で表示される
2. **Given** カテゴリ内の商品を購入済みにして一覧から非表示にした後、**When** ユーザーが残った商品を確認すると、**Then** 残った商品も引き続きひらがな昇順で表示される
3. **Given** 購入リスト画面が表示されている状態で、**When** ユーザーが新しい商品を追加すると、**Then** 追加した商品は所属カテゴリ内でひらがな昇順の適切な位置に表示される

---

### User Story 2 - 読みが同じ商品が複数ある場合でも正しく並ぶ (Priority: P2)

買い物をする人として、同じひらがな読みを持つ商品が複数あるカテゴリでも、安定した順序で商品が表示されるので混乱せずに使いたい。

**Why this priority**: 同音商品の並び順が不安定だとユーザー体験が低下するが、発生頻度は低いため P2 とする。

**Independent Test**: 同じひらがな読みを持つ複数の商品をリストに登録し、購入リスト画面で同一カテゴリ内の表示順が画面遷移をまたいでも変化しないことを確認する。

**Acceptance Scenarios**:

1. **Given** 同じひらがな読みを持つ複数の商品が同一カテゴリに登録されている状態で、**When** ユーザーが購入リスト画面を開くと、**Then** 同音商品は一定の安定した順序（例: 商品名の文字列順）で並ぶ
2. **Given** 同音商品が含まれるリストを複数回開いた状態で、**When** ユーザーが商品の並びを確認すると、**Then** 毎回同じ順序で表示される

---

### Edge Cases

- ひらがな読みが未設定の商品は、カテゴリ内でひらがな読みが設定された商品の後ろ（末尾）に配置される
- カタカナ表記の読みは、ひらがなに正規化して比較することでひらがな読みと混在しても正しく並ぶ
- 商品が1件だけのカテゴリでは、並び順の変更が視覚的に発生しない（問題なし）
- カテゴリ間の並び順（カテゴリ自体の順序）は本機能の対象外で変更しない

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 購入リスト画面の各カテゴリ内において、商品はひらがな読み（`hiragana` フィールド）の昇順で表示されなければならない
- **FR-002**: ひらがな読みが等しい商品が複数存在する場合、商品名（表示名）の文字列昇順をタイブレーカーとして使用しなければならない
- **FR-003**: ひらがな読みが未設定（空）の商品は、読みが設定された商品の後ろ（末尾）に配置されなければならない
- **FR-004**: カタカナ読みはひらがなに正規化したうえでソートに使用しなければならない
- **FR-005**: カテゴリ間の表示順（カテゴリ自体の並び）は本機能によって変更してはならない
- **FR-006**: 商品の購入済み操作・新規追加など、リストの内容が変化した後も、並び順はひらがな昇順が維持されなければならない

### Key Entities

- **商品 (Item)**: 購入リスト画面に表示される買い物リストの1件。`hiragana`（ひらがな読み）フィールドをソートキーとして使用する
- **カテゴリ (Category)**: 商品をグループ化する単位。カテゴリ内の商品の並び順が本機能の対象

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 購入リスト画面を開いたとき、すべてのカテゴリ内の商品がひらがな昇順で正しく並んでいる（並び順一致率 100%）
- **SC-002**: ひらがな読みが未設定の商品が含まれる場合でも、読みが設定されている商品はひらがな昇順で正しく表示される
- **SC-003**: 商品の追加・購入済み操作の後、追加操作なしで（画面リロード不要で）並び順がひらがな昇順に維持される
- **SC-004**: カテゴリ自体の並び順が本機能導入前後で変化しない

## Assumptions

- 商品データには `017-item-hiragana-search` で導入された `hiragana` フィールドが既に存在し、多くの商品で読みが登録済みであることを前提とする
- ひらがな昇順のソートは日本語ロケール（JIS かな順）に基づく
- 本機能はカタカナ→ひらがな変換のみ行い、漢字→ひらがな変換（読み推定）は行わない
