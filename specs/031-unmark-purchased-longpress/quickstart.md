# クイックスタート: 購入済み解除の検証

## 自動テスト

```powershell
cd weekly_buyer
flutter test test/repository_test.dart test/widget_test.dart
flutter analyze
```

確認する内容:

- リポジトリ: 購入済み商品に `unmarkPurchased` を実行すると `isPurchased=false` かつ `purchasedAt=null` になる。未購入・不存在 ID でも例外なし。
- ウィジェット: 購入済み商品を長押しするとダイアログが出る。「はい」で未購入表示、「いいえ」で変化なし。未購入商品の長押しではダイアログが出ない。

## 手動確認

1. 商品追加画面で商品を登録し、購入済みにする。
2. 購入済みの商品を長押しし、確認ダイアログが表示されることを確認する。
3. 「いいえ」を選び、購入済みのままであることを確認する。
4. 再度長押しして「はい」を選び、通常色・購入日なしの未購入表示に戻ることを確認する。
5. アプリを再起動し、未購入のままであることを確認する。
6. 未購入商品の長押しで何も起きないこと、前の週の表示で長押しが無効なことを確認する。
