# データモデル: 購入済み解除

スキーマ変更・マイグレーションはない。既存テーブル `weekly_list_items` の状態遷移のみ追加する。

## 対象エンティティ: 週間リスト明細（商品）

| 項目 | 型 | 解除時の変化 |
|------|----|--------------|
| `id` | int | 変化なし（対象の特定に使用） |
| `is_purchased` | bool | `true` → `false` |
| `purchased_at` | DateTime? | 値あり → `null` |
| `updated_at` | DateTime | 現在時刻に更新 |
| その他（名前・数量・曜日・区分・カテゴリ・並び順） | — | 変化なし |

## 状態遷移

```text
未購入 --(タップ/フリック等の既存操作)--> 購入済み
購入済み --(長押し → 「はい」)--> 未購入        ← 本機能
購入済み --(長押し → 「いいえ」/閉じる)--> 購入済み（変化なし）
未購入 --(長押し)--> 未購入（何も起きない）
```

## 検証ルール

- 解除は冪等。すでに未購入、または存在しない ID でもエラーにせず、他の行に影響しない。
- 解除後は `purchased_at` が残らない（購入日表示が消える）。
- 一時的な UI 状態（ダイアログの表示）は永続化しない。
