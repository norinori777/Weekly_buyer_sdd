# UI 契約: 購入済み解除の長押し操作

対象: 商品追加画面（`ItemAddDestination`）の商品行（`_SectionPreviewCard`）

## トリガー

| 条件 | 長押しの結果 |
|------|--------------|
| 購入済み商品 かつ 編集可能な週 | 確認ダイアログを表示 |
| 未購入商品 | 何も起きない |
| 読み取り専用の週（前の週） | 何も起きない |

## 確認ダイアログ

- 種類: `AlertDialog`
- タイトル: 「購入済みを解除しますか？」
- 本文: 対象商品名を含める（例:「『{商品名}』の購入済みを解除します。」）
- ボタン: 「いいえ」（`false`）、「はい」（`true`）
- 外側タップ・戻る操作: `null` 扱いで「いいえ」と同じ（変更なし）

## 結果

| 選択 | 動作 |
|------|------|
| はい | `unmarkPurchased(item.id)` を実行し、スナップショットを再読込。行は未購入の見た目（通常色・購入日なし）になる |
| いいえ / 閉じる | 状態変更なし |

## リポジトリ契約

```dart
Future<void> unmarkPurchased(int itemId);
```

- 事前条件: なし（不存在・未購入でも安全）
- 事後条件: 対象行が `isPurchased=false`、`purchasedAt=null`
- 例外: 通常の DB エラー以外は投げない

## 既存操作への影響

- 削除ボタン、料理メニュー操作、購入リスト画面の購入済み／元に戻す操作は変更しない。
