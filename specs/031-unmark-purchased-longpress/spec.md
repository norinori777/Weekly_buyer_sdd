# Feature Specification: 購入済み商品の長押しによる購入済み解除

**Feature Branch**: `031-unmark-purchased-longpress`  
**Created**: 2026-10-25  
**Status**: Draft  
**Input**: User description: "商品追加画面で追加した商品のリストがありますが、購入済みの商品を長押ししたら、購入済みを解除するか確認するプロンプトが表示され、「はい」を選択すると購入済みを解除する機能を追加してください。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 購入済みを長押しで解除する (Priority: P1)

ユーザーは誤って購入済みにした商品、または買い直しが必要になった商品を、商品追加画面の商品リスト上で長押しすることで未購入の状態に戻したい。

**Why this priority**: 購入済みの誤操作を取り消せない現状の不便を解消する、この機能の中核である。

**Independent Test**: 購入済みの商品を1件用意し、リスト上で長押しして確認プロンプトで「はい」を選択すると、その商品が未購入の状態に戻ることを確認できる。

**Acceptance Scenarios**:

1. **Given** 商品追加画面のリストに購入済みの商品がある, **When** その商品を長押しする, **Then** 購入済みを解除するか確認するプロンプトが表示される
2. **Given** 確認プロンプトが表示されている, **When** 「はい」を選択する, **Then** その商品の購入済みが解除され、リスト上で未購入の表示になる
3. **Given** 購入済みを解除した商品がある, **When** アプリを再起動して商品リストを開く, **Then** その商品は未購入のままである

---

### User Story 2 - 確認をキャンセルする (Priority: P2)

ユーザーは長押しが誤操作だった場合に、購入済みの状態を保ったままプロンプトを閉じたい。

**Why this priority**: 誤操作による意図しない解除を防ぐための安全策である。

**Independent Test**: 購入済み商品を長押しし、プロンプトで「いいえ」を選択すると、状態が変わらないことを確認できる。

**Acceptance Scenarios**:

1. **Given** 確認プロンプトが表示されている, **When** 「いいえ」を選択する（またはプロンプト外をタップして閉じる）, **Then** プロンプトが閉じ、その商品は購入済みのままである

---

### Edge Cases

- 未購入の商品を長押しした場合は、確認プロンプトを表示せず、何も変わらない。
- 購入済みを解除した商品が、購入済みの表示・並び順・集計（購入日や件数など）に反映され、購入済みとしての情報が残らない。
- 確認プロンプト表示中に画面を回転した場合も、プロンプトの状態が失われず操作を続けられる。
- 購入済み商品の通常のタップ操作など、既存の操作は従来どおり動作する。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: システムは、商品追加画面の商品リスト上の購入済み商品に対する長押し操作を検出しなければならない。
- **FR-002**: システムは、購入済み商品が長押しされたとき、購入済みを解除するかを確認するプロンプトを表示しなければならない。
- **FR-003**: プロンプトは「はい」と「いいえ」の選択肢を提供しなければならない。
- **FR-004**: ユーザーが「はい」を選択したとき、システムは対象商品の購入済み状態を解除し、リストの表示に即座に反映しなければならない。
- **FR-005**: システムは、購入済みの解除結果を保存し、アプリ再起動後も維持しなければならない。
- **FR-006**: ユーザーが「いいえ」を選択した、またはプロンプトを閉じたとき、システムは商品の状態を変更してはならない。
- **FR-007**: システムは、未購入の商品に対する長押しで確認プロンプトを表示してはならない。
- **FR-008**: 購入済みを解除した商品は、購入済みに関連する情報（購入日など）をリスト上に表示してはならない。

### Key Entities

- **商品**: 商品追加画面のリストに表示される項目。購入済み／未購入の状態と、購入済み時に紐づく購入日などの情報を持つ。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: ユーザーは、購入済み商品の長押しから解除完了までを3操作以内（長押し、「はい」選択）で行える。
- **SC-002**: 「はい」を選択してから1秒以内に、リスト上の表示が未購入状態に更新される。
- **SC-003**: 解除した商品の未購入状態が、アプリ再起動後も100%維持される。
- **SC-004**: 「いいえ」選択またはプロンプトを閉じた場合、商品状態が変化する事例が0件である。

## Assumptions

- 対象は商品追加画面に表示される商品リストのみで、他の画面は対象外とする。
- プロンプトの文言は日本語で、購入済みの解除であることが分かる内容とする。
- 解除は1商品ずつ行い、複数商品の一括解除は対象外とする。
- 既存の購入済み状態の保存の仕組みを利用し、新たな外部サービスは不要とする。
